# radio_comunicacao

Projeto 2 — Rádio/Comunicação. Apenas dados de outorga pública.

- `ingestion/`  — ingestão dos dados abertos da Anatel. Sem LLM.
- `agents/`     — orquestração multi-agente (LangGraph).
- `mcp_server/` — tools de acesso a dado do domínio, expostas via MCP.
- `rag_corpus/` — corpus regulatório (atos normativos da Anatel).
