# satelite_agro

Projeto 1 — Satélite + Agro/GIS (região piloto: Rio Grande do Sul).

- `ingestion/`  — pipelines de ingestão e fusão (MapBiomas, IBGE). Sem LLM.
- `agents/`     — orquestração multi-agente (LangGraph).
- `mcp_server/` — tools de acesso a dado do domínio, expostas via MCP.
- `rag_corpus/` — corpus de metodologia (documentos técnicos do MapBiomas).
